# Snake Game 🐍

This is a nostalgic game inspired by the classic Snake game on old Nokia phones.

🎮 **Play it online:** [Snake Game](https://aliscripter.github.io/Snake_Game/)

## About the Game
- The game is controlled using the **keyboard**.
- It is **not highly responsive for mobile devices**.
- Built with **vanilla JavaScript and CSS**, making it a great project for learning JavaScript concepts.

## Features & Concepts Used
- Functions
- Event listeners & DOM manipulation
- Playing music with JavaScript
- Using **Local Storage** to save game data
